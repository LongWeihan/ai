项目

  • OverSearchGuard

    面向 RAG / Agent 的冲突感知证据裁剪（evidence thinning）。

    • CACT：融合来源可靠度、时间衰减、矛盾惩罚与 cap-per-source 反重复的冲突感知候选裁剪。
    • BEA：预算内逐步加证据的成本导向策略（TPC 指标）。
    • 可复现实验：准确率 0.143 → 0.970，同时平均 tokens 491.5 → 117.3（flan-t5-small，n=300）。
  • FlashToken

    Tokenizer 端前缀缓存：让低延迟 LLM 系统的 tokenization 更快（tiktoken）。

    • 固定前缀复用 + append-only 增量编码两种策略，贴合 KV-cache 工作流。
    • 在长前缀复用场景实现 27×–37× speedup，且 mismatches = 0（逐 token 一致）。
  • Turbo-Softmax

    面向通用 MCU 的高精度快速 Softmax（C）。

    • 通过 IEEE-754 位级操作做 Range Reduction，并用 5 阶多项式近似 exp。
    • 相对 math.h 实现获得 4.0×–4.2× speedup；最大误差 < 1e-6。
